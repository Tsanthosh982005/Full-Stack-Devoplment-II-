# FSD-II Experiments Repository

## Full Stack Development – II

Welcome to my **Full Stack Development-II (FSD-II) Experiments Repository**.

This repository contains practical experiments completed as part of my B.Tech Computer Science and Engineering coursework at Sree Rama Engineering College, Tirupati.

The experiments cover JavaScript, DOM manipulation, React.js, Node.js, Express.js, REST API concepts, and database connectivity.

## 📚 Experiments List

### 1. Introduction to Modern JavaScript and DOM

| No. | Experiment | Description |
|---|---|---|
| 1(a) | Linking JavaScript with HTML | Connecting an external JavaScript file to an HTML page. |
| 1(b) | HTML DOM Selectors | Selecting HTML elements using ID, class, tag name, querySelector and querySelectorAll. |
| 1(c) | Event Listeners | Implementing click, mouseover, mouseout and keyboard events. |
| 1(d) | Button Click Events | Handling multiple HTML button click events using JavaScript. |
| 1(e) | JavaScript Functions | Implementing function declarations, function expressions and arrow functions. |

### 2. Basics of React.js

| No. | Experiment | Description |
|---|---|---|
| 2(a) | Counter Using Class Components | Creating a counter application using React class components. |
| 2(b) | Counter Using Functional Components | Developing a counter using React functional components. |
| 2(c) | Button Click Events | Handling button click events in React functional components. |
| 2(d) | Conditional Rendering | Displaying components conditionally based on login status. |
| 2(e) | String Literals | Displaying dynamic text using JavaScript string literals in React. |

### 3. Important Concepts of React.js

| No. | Experiment | Description |
|---|---|---|
| 3(a) | useState Hook | Implementing a counter application using the useState hook. |
| 3(b) | useEffect Hook | Fetching user data from an API using the useEffect hook. |
| 3(c) | Props | Sharing data between two React components using props. |
| 3(d) | React Forms | Creating and handling forms using React state. |

### 4. Introduction to Node.js and Express.js

| No. | Experiment | Description |
|---|---|---|

## ⚙️ How to Run

### JavaScript Experiments

```bash
node filename.js
```

For HTML and DOM experiments, open the corresponding HTML file in a web browser.

### React Experiments

```bash
npm install
npm start
```

For Vite-based projects:

```bash
npm install
npm run dev
```

### Node.js and Express.js Experiments

Install the required packages:

```bash
npm init -y
npm install express
```

For the database connectivity experiment:

```bash
npm install express mysql2
```

Run the application:

```bash
node app.js
```

Open the following URL in your browser:

http://localhost:3000
